# Data Model: Caramel AI Tech Support Chat (001-psec)

**Date**: 2026-11-21
**Storage**: In-process memory only. No database (spec FR-017, constitution V).

## ChatSession

One continuous conversation.

| Field | Type | Rules |
|-------|------|-------|
| `sessionId` | string | Generated by the browser client. Required on every request. Non-blank. |
| `messages` | ordered list of Message | Grows with each turn. Cleared by "New chat" or lost on restart. |
| `createdAt` | instant | Set on first message. |
| `requestWindow` | rate-limit counter | Tracks request count per time window for rate limiting (FR-013). |

**Lifecycle**: Created on the first message for a `sessionId`. Ends when the user starts a new chat
(the client generates a new `sessionId`) or the backend restarts.

## Message

| Field | Type | Rules |
|-------|------|-------|
| `role` | enum: `USER`, `ASSISTANT`, `SYSTEM` | `SYSTEM` is the persona prompt and is never shown to the user. |
| `text` | string | `USER`: at most 2,000 characters, non-blank. `ASSISTANT`: may be partial if the reply failed. |
| `createdAt` | instant | Set when the message is recorded. |

**Logging rule**: `text` MUST NOT be written to logs (constitution IV, FR-016).

## ReplyStatus

State of one assistant reply.

```text
PENDING ──first token──▶ STREAMING ──complete──▶ COMPLETE
   │                         │
   └────── failure ──────────┴──────────────▶ FAILED
```

| State | Meaning | UI effect |
|-------|---------|-----------|
| `PENDING` | Request sent, no token yet | Pending indicator shown (FR-004) |
| `STREAMING` | Tokens arriving | Text appended progressively (FR-002) |
| `COMPLETE` | Stream finished normally | Indicator cleared |
| `FAILED` | Timeout, outage, or stream error | Friendly message shown; partial text kept; user may retry (FR-011) |

## Validation summary

| Rule | Source |
|------|--------|
| `sessionId` required and non-blank | Spec Key Entities, FR-005 |
| Message non-blank and at most 2,000 characters | FR-012, spec edge cases |
| Per-session request rate limit | FR-013 |
| Origin restricted to frontend | FR-014 |
